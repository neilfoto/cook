# 家常煮意｜七十道家常菜譜（預覽）

這是一個離線即可瀏覽的靜態預覽網站，收錄七十道較健康的家常菜：五十道中式，以及二十道港式西餐。每款皆為四人份，附食材、調味、煮法與完成圖。本預覽並非公開網站，亦尚未發佈。

本站與學校或科目教材無關，並無校徽或學校資料。

## 如何預覽

1. 解壓壓縮檔 `chinese-home-cooking-preview.zip`。
2. 進入資料夾 `chinese-home-cooking-preview`。
3. 用瀏覽器開啟 `index.html`（可直接以檔案方式開啟，亦可把整個資料夾放到本地伺服器再瀏覽）。
4. 在首頁以分類、菜系（中式／西式）、辣度、做法或搜尋篩選菜譜，點選卡片即可查看完整食譜與完成圖。做法篩選包括焗飯與炆飯。

建議使用較新版本的 Chrome、Edge、Safari 或 Firefox。若電腦已連線，頁面會載入「思源黑體／思源宋體」；即使字型未能載入，仍會改用系統中文黑體，不影響內容。

## 內容說明

- 份量一律以四人家庭晚膳為準。
- 「較健康」是指多用蔬菜，以及蒸、灼、炆、煮、焗飯、炆飯、適量油炒等做法，並非營養標示或醫療建議。
- 焗飯是把澆頭與芝士鋪在飯上入爐；炆飯是把米與配料一鍋慢炆，兩者並不相同。
- 七十道之中有八道標示為「辣」：麻婆豆腐、魚香茄子、宮保雞丁、酸辣湯、魚香肉絲、豉椒炒魷魚、椒絲腐乳通菜、香辣番茄意粉。其餘均為不辣或僅作配色。
- 烹調時間僅供參考，實際火候須以食材完全熟透為準。

## 資料夾結構

- `index.html`：頁面入口
- `css/style.css`：樣式

- `images/`：各菜完成圖
